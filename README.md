# E-Commerce Sales Analysis Using SQL

## 📌 Project Overview

This project analyzes e-commerce sales data using SQL to understand sales performance, customer behavior, product performance, and revenue trends.

The project was created as part of my journey toward becoming a Data Analyst and focuses on applying SQL concepts to real-world business questions.

---

## 🎯 Business Objective

The main objective of this project is to use SQL to extract meaningful insights from e-commerce data and answer important business questions related to:

- Sales and revenue
- Customer purchasing behavior
- Product performance
- Category performance
- Monthly sales trends
- Customer spending
- Business performance

## 🗂️ Database Structure

The database consists of four main tables:

### 1. Customers
Contains information about customers.

**Columns:**
- customer_id
- customer_name
- city
- country
- signup_date

### 2. Products
Contains information about products.

**Columns:**
- product_id
- product_name
- category
- price

### 3. Orders
Contains information about customer orders.

**Columns:**
- order_id
- customer_id
- order_date

### 4. Order Items
Contains details about products included in each order.

**Columns:**
- order_item_id
- order_id
- product_id
- quantity
